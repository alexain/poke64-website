Features

A C64 emulator that exposes the machine.

POKE64 is built around a full emulation workflow: media, drives, memory expansions, audio hardware and iPad-native controls all live in one coherent interface.

Core emulation

POKE64 uses the VICE x64sc family as its C64 emulation foundation. The frontend is native to Apple platforms and is responsible for presentation, media management, settings and device integration.

  • PAL/NTSC-oriented C64 emulation through VICE.
  • ReSID, ReSID-FP and FastSID engine choices where exposed by the bundled core.
  • Second SID address options for compatible 2SID software.
  • CRT cartridge attachment with VICE cartridge autodetection, including compatible Prophet64 CRT images.

Drives and storage

Disk access can favor speed or hardware fidelity depending on the title.

  • Fast Virtual Drive: VICE device traps bypass the full serial-drive path when compatible.
  • True Drive: full drive and IEC behavior, with optional Automatic or Maximum load acceleration.
  • Multiple IEC drive units, including units 8 through 11 in the current development line.
  • D64, D71, D81 and G64 support in the current public feature set.

Memory and peripherals

  • REU configurations up to 16 MB.
  • IEC printer workflow, including RAW output fallback when printer ROMs are unavailable.
  • Virtual modem support for compatible software and user-selected network destinations.
  • Mouse support and modern controller input.

iPad experience

  • Native media library rather than emulator-style filesystem navigation.
  • On-screen C64 keyboard and input controls.
  • Responsive portrait and landscape layouts.
  • Peripheral status panels kept visible around the emulation canvas.
  • Save-state and profile workflows designed around individual titles and machine configurations.
Not bundled: copyrighted Commodore ROMs, proprietary peripheral firmware and commercial software images must be supplied by the user where legally permitted.
