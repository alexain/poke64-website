Support

Need help with POKE64?

Start with the checks below. For reproducible bugs or compatibility reports, GitHub Issues is the preferred public support channel during the beta.

Report a bug

Include your POKE64 version/build, iPad model, iPadOS version, media type and the exact steps that reproduce the issue.

Open GitHub Issues

Releases and source

Public source code, change history and unsigned sideloading builds are available from the project repository.

View releases

Before reporting a problem

  • Check whether the title requires True Drive instead of Fast Virtual / Traps.
  • If an expansion is involved, record the configured REU size, SID address, drive model or firmware profile.
  • For a display or input issue, specify portrait/landscape orientation and whether the on-screen keyboard was open.
  • For TestFlight builds, include the visible version and build number from About.

ROMs and firmware

POKE64 does not distribute Commodore ROMs, proprietary peripheral firmware or commercial games. Support cannot provide copyrighted ROM or software downloads. Where POKE64 can operate without an optional firmware image, the interface may offer a compatible fallback.

Contact

During the beta, use GitHub Issues for technical reports. A dedicated support email can be enabled by setting supportEmail in assets/js/config.js before the App Store launch.
