# Screenshots

Place final App Store / website screenshots here and reference them from the HTML pages.

Suggested filenames:

- `hero-landscape.webp`
- `portrait.webp`
- `library.webp`
- `settings.webp`
- `keyboard.webp`
- `hardware.webp`

Recommended export: WebP, 1600-2200 px wide for landscape screenshots, with no embedded device frame.
